# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in **SynapseCode**, please report it privately by sending an email to **abdallahdiouf.dev@gmail.com**.

Please include:
* Description of the vulnerability
* Steps to reproduce
* Potential impact

We will respond within 48 hours to acknowledge receipt and coordinate a patch and responsible disclosure.

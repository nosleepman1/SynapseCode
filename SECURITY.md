# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Supported |

## Reporting a Vulnerability

If you discover a security vulnerability in SynapseCode, please report it privately by emailing `abdallahdiouf.dev@gmail.com`.

Please provide:
* A summary description of the vulnerability.
* Minimal reproduction steps or sample repository.
* Assessment of the potential security impact.

The project maintainers will respond within 48 hours to confirm receipt and coordinate a patch and disclosure timeline.
